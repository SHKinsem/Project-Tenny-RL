通用回归包含动态网络形状与激活、不同环境数、物理子步、首回合计账、终止/截断/重置、seed、原子取消、GIL 释放和同对象并发拒绝。单摆的 `nq/nv/nu=1/1/1`、观测/动作维数 `3/1`，与轮腿的 `13/12/4`、`24/4` 共用同一个评估核心。MLP 算法用独立 NumPy 数学对照；任务物理使用独立 MuJoCo C API 对照。

18 组轮腿短轨迹对照中，直接扭矩的 qpos/qvel/ctrl 逐位相同；另两模式使用独立空间 `mj_jac` 参考，最大 qvel 差约 6.0×10⁻¹⁵。6 组重置检查逐位核对重复 episode 的观测、动作、状态、ctrl、奖励、done，确认历史清零及只累计首回合。这是重置的一致性验证；其他两种模式尚没有独立完整奖励 oracle 或训练策略长轨迹对照。

## 同模型数值与耗时

固定 run `20261115T035858.979961Z_58862508`，腿力＋轮扭矩、standing_v2、固定 BC 归一化、确定性策略、零命令/无噪声/无推扰。复用原 GPU 保存的物理初态和参考锚点，8 环境 × 600 控制步，100 Hz 控制 / 400 Hz 物理，共 19,200 个物理步。

| 完整评估调用 | 中位耗时 | 比较范围 |
| --- | ---: | --- |
| C++ 原生 | **0.196 秒** | 本轮三次无 trace：0.197 / 0.188 / 0.196 秒 |
| GPU MJX | 3.938 秒 | 原同模型基准：10.555 / 3.832 / 3.938 秒，保留延迟预热 |
| Python＋原生 MuJoCo | 4.369 秒 | 本轮重测：4.369 / 4.358 / 4.382 秒 |

相对此前同机 GPU 基准约 **20.1 倍**，相对此次 Python CPU 重测约 **22.3 倍**。模型建立 0.069 秒，首次含 trace 调用 0.198 秒，分别记录。公开 CLI 的另一次四轮检查得到无 trace 中位 0.193 秒。上述耗时包含完整执行、统计和绑定返回；没有把 trace 文件写入计时，也没有测本轮 GPU 或端到端 PPO。

关键数值结果：

- 64 个共同观测的动作最大差 2.44×10⁻⁶。
- 对 GPU 首步 qpos 最大差 4.86×10⁻⁹，qvel 1.63×10⁻⁷，奖励 2.89×10⁻⁶。
- 8 个首回合均为 600 步，未提前终止；done 序列相同。
- 累计回报最大相对差 **0.0467%**，低于预设 1%。
- 世界 0 的闭环 pitch_sin 最大差 0.0002294，机体位置最大差 **0.1504 mm**。

CPU/GPU 闭环不会逐位相同：归一化动作的全程最大差约 0.0490。报告按既定策略、状态、回报及终止门槛判断等价，没有修改阈值；不能将其描述成每一步动作完全相同。

不同拓扑的单摆另测 3 环境 × 600 控制步 × 4 物理子步：C++ 三次 0.00576 / 0.00999 / 0.00970 秒，Python MuJoCo 批量 `nstep=4`＋观测/奖励参考为 0.01560 / 0.01399 / 0.01396 秒，累计回报差为 0。它证明相同接口可以测量另一个任务；这种毫秒级小任务计时有明显波动，不外推成通用加速率。

## 尚未覆盖

生产 PPO 中替换评估后的参数传输、总训练墙钟收益和网页生命周期集成尚未实施。噪声、推扰、动力学随机化、采样/变化命令、历史观测、延迟、RNN 和任意网络都不属于当前能力；相关配置明确拒绝。轮腿固定非零命令的奖励轨迹没有独立对照。当前只验证 Linux/WSL 构建和单原生控制线程，未验收其他操作系统或多线程性能。
