# 档案格式

每个商品一个目录：`product.md`、`images/01-overview.png` 等；仅在详情很长时增加 `details.md`。下面的占位内容应全部替换为真实观察，缺失写“未确认”。结构随原页模块顺序调整，不制造原页没有的栏目。

```markdown
---
source: "https://item.taobao.com/item.htm?id=商品ID&skuId=请求的SKU"
item_id: "商品ID"
requested_sku_id: "链接SKU或未指定"
captured_at: "带时区的ISO时间"
status: "complete / partial / blocked 三选一"
---

# 原商品标题

店铺：原店铺名。用途/品类：一行事实摘要。以下为抓取时页面信息。

## 价格与规格

| 项目 | 页面信息 | 证据 |
|---|---|---|
| 显示价格 | CNY 数值或区间；起价/促销条件 | 图01 |
| 当前选项 | 每个规格维度的完整选中值；未选择则写明 | 图01/02 |
| 页面SKU ID | 观察值或未确认；独立于请求SKU | 页面规格区 |
| 包装/单位 | 每包件数、计价单位；未知明确写出 | 图02 |
| 规格选项 | 按维度列出可见选项；标明仅覆盖哪些 | 页面规格区 |

![图01：商品概览与显示价格（页面截图）](images/01-overview.png)

## 产品参数

| 参数 | 值及单位 | 证据 |
|---|---|---|
| 型号/尺寸/额定值等实际字段 | 按原页记录，保留条件及公差 | 图03或参数区 |

## 商品详情

将各组图片放在对应短说明下，保持原页顺序。每图一句用途说明；关键图中文字进入上面的参数表。

![图03：尺寸图，标出接口与安装尺寸（页面截图）](images/03-dimensions.png)

## 配送与售后

仅列观察到的发货地、时效、运费适用条件、售后；未知运费写“未确认”。不保存收件地址。

## 覆盖与未确认

- 已查看：概览、指定规格、参数区、详情末尾等实际范围。
- 未覆盖/待确认：具体字段或模块；无则写“无”。
- 事实冲突：保留两处值及各自证据；无则省略此行。
```

阻塞时仍生成 `product.md`，保留 source、requested_sku_id、时间、status 与具体阻塞原因，不虚构标题/价格或填充空表；没有商品截图就明确写“商品图未取得”。

## Token 与来源

- 事实记录一次，图注只说图片用途。长的 SKU 组合和补充文字移入 details.md，主档用说明性链接指向。
- 图片相对路径便于目录搬迁；向用户交付时使用绝对 product.md 文件链接。报告图片时使用绝对路径，避免渲染失败。
- 截图是本地证据，不是独立制造的商品图片。保存快照全文、工具日志和追踪 URL 不作为默认交付物。缺失内容保持未确认，不用模型常识补成卖家声明。
