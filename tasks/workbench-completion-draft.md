# 工作台功能补齐草稿

本轮授权：在当前 Worktree 补齐六项既有待办；隔离测试通过后发布。保留已部署训练加速和正在运行的训练。新增需求先在这里记录，再整理交接。

## 交互与合同

- 真正暂停训练：`POST /training` 的 `pause` / `resume`，进程在参数回调安全边界停留，优化器和网络继续驻留；等待阶段与已暂停分别显示。暂停时长不计入预算/累计训练时间，停止在暂停中仍可执行。旧进程没有控制协议时禁用，不能重启训练补能力。
- 手动保存：`POST /training` 的 `save`，返回请求 ID；回调持有的参数保存为独立 checkpoint，完成/失败由状态确认，HTTP 接受不表示已经保存。保存时不停止训练，不覆盖既有 checkpoint。暂停期间也可保存。
- 历史续训：选择经过实际兼容性验证的 checkpoint；将精确路径传给 start，不能偷偷改为最新。累计进度继承所选模型旁路元数据；历史未知仍为未知。跨进程恢复网络与归一化，优化器是否恢复必须按实际实现标注。
- 参数：独立 schema 描述允许编辑的 PPO/并行/评估字段，启动时完整校验；生效值同时进入实际 Brax 调用和 ppo_config。训练中锁定，下次训练才应用。默认仍为现有 auto/继承五配置，不能绕开兼容验证或改默认性能策略。
- 多预览：最多四个独立 CPU 仿真实例，按需打开、关闭、释放；每次打开同步一次，查看中固定模型版本。每窗有自己的暂停/重置与状态，不启动额外训练，不常驻 GPU 评估。
- 目录与导入：本机桥接负责原生选择/打开目录；后端校验目录、模型与兼容合同。可指定后续 checkpoint 保存目录，活动训练位置不能改变；导入模型完整复制/验证后才可用于续训。不用任意命令执行伪装目录能力。
- 预加载：首次连接、模型同步、环境/策略加载与准备阶段均有可见反馈。确有分母才显示真实百分比，其余显示不定进度条和阶段名称；不把等待动画算作训练进度，错误可重试，关闭后取消且迟到响应不重开。

## 实现边界

- 新协议放非指纹 timed 包装层/新模块；console_train/control_modes/preview_sync、环境/映射/奖励/模型资产以及 runtime_defaults 字节保留。
- 新控制以 run ID、协议版本、请求 ID 绑定，重复请求幂等；新旧 web 可并存，旧训练能力据状态判断。
- UI 保持黑白灰、克制绿点、少线条、严格层级/缩进；载入条复用现有底部/视窗空间，不新增冗余标题行。
- 发布使用独立版本目录/固定 Windows 桥接副本；不覆盖活跃训练可能再导入的源码，不中断训练。测试产物不参与生产 latest 选择。

## 验收

- 协议并发、暂停计时、暂停中停止/保存、重复保存、终态/旧协议拒绝、参数合法性和实际落地、历史精确选择/兼容拒绝、目录映射/导入完整性、多窗隔离/取消/释放、未知/真实加载进度均有针对性测试。
- 原有运行配置、计时、原生评估、旁路累计、只读合同与桥接回归通过；核对受保护源码指纹。
- Terra 用隔离页面验收完整操作与加载状态，生产只读验收且最终关闭新增预览。只有不争用正在运行训练的条件下才做短 GPU 验收。
- 发布前后记录训练 PID/启动时间、run ID、步数和加速配置，确认未更换进程且继续推进。

## 收尾与后续边界

- 本轮六项与加载反馈已完成并发布，验收详见 tasks/todo.md review 与 docs/workbench-controls.md。首次初始化、mode query、stream generation及真实首帧错误均补了回归。
- 预览为独立CPU实例，最多四窗，总帧预算受限；真实四窗约2FPS/窗。进一步原生预览加速保留为后续优化，不改当前训练加速合同。
- 同进程暂停保留优化器；跨进程checkpoint续训仍恢复网络/归一化并重建优化器，接口明确false。完整训练状态迁移须另设持久协议，不能把权重快照冒称完整优化器恢复。
- 新机器人完整robot/task/action/policy/runtime语义合同和真实第二实现仍为机构迁移工作；本轮未改模型、奖励、动作映射或固件。
