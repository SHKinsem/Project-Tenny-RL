# 停车保持：位置锚点与朝向锚点

日期：2026-08-31  
相关现象：`docs/stand_tall_extend_issue.md`

停车要锁的是**位置**和**朝向**，不是左右轮相位加一个 yaw。本文写清原由、运动学定义、训练/推理怎么做。观测语义与按独立轮相训练的旧策略不兼容，落地后需重训。

## 1. 锚点要干什么

| 锚点 | 目的 |
|---|---|
| 朝向 \(\psi_0\) | 稳定在一个航向 |
| 位置 \(s_0\) | 稳定在一个位置 |

- 有前进指令：位置原点跟着走（在走，不保原地）；朝向原点冻住（直行保向）。
- 有偏航指令：朝向原点跟着转；位置原点冻住（原地转不该清掉“停在哪”）。
- 停车：两套都冻，策略把 \(\Delta s\)、\(\Delta\psi\) 收到 0。

不要用三个原点（左轮相、右轮相、yaw）。左右独立保轮相等于同时锁弧长和差动航向，再加 IMU 航向，航向被锁两次。

## 2. 原由

差速、无滑移时，两个轮子只提供两个量：

\[
s = R\,\frac{\theta_L+\theta_R}{2}
\qquad
\psi_w = \frac{R}{W}\,(\theta_R-\theta_L)
\]

\(s\) 是沿轨迹弧长（位置），\(\psi_w\) 是轮推航向。姿态 / IMU 再给一条 \(\psi\)。平面 hold 需要的是 \((s,\psi)\)。

冻 \(\theta_{L0},\theta_{R0},\psi_0\) 会过约束：

- 共模要把弧长拧回旧轮相 → 机器人走一段（把相位当成了位置）
- 差动要把 \(\psi_w\) 拧回旧左右差 → 机器人转
- IMU 还要回到另一条 \(\psi_0\)

随机站起时轮在打滑或离地里转过很多，三路原点仍停在 reset 那一帧，冲突最大。先走再停把轮相位锚点刷成当前值，差动冲突暂时消失——那是清掉了错误目标，不是学会了保位置。`stand_tall_extend_issue.md` 实验 A/B 即此。

在三锚点上再做 clip、或把左右轮误差改写成与 yaw 一致的差动，都是补丁：根上仍把轮相当成位置。左右轮相位分别惩罚，等于把差动（航向）又罚一遍，和“轮锚点 = 位置”相反。

## 3. 原理

### 3.1 只冻 \((s_0,\psi_0)\)

每步代数计算（训练用这个，不用滤波器）：

- \(s=(q_L+q_R)/2\)：未饱和左右轮角共模。本模型左右铰链轴向同向，同号 \(q\) 表示同向滚动（前进时两侧一起增加），**不要**写成 \((q_L-q_R)/2\)。
- \(\psi\)：只用姿态 / IMU。轮差动 \((q_L-q_R)\) 属于航向，不作为第二个朝向目标。

\(\Delta s = s - s_0\)，\(\Delta\psi = \psi - \psi_0\)。差动属于航向，不进入位置误差。两路正交，没有“以谁为主”。

现网 `sin(q·0.1)/0.1` 大角度饱和，内部状态不要用它当 \(s\) 的积分器。

### 3.2 何时刷新原点

| 指令 | \(s_0\) | \(\psi_0\) |
|---|---|---|
| \(\lvert v_x\rvert\) 过死区 | 刷成当前 \(s\) | 不动 |
| \(\lvert \omega_z\rvert\) 过死区 | 不动 | 刷成当前 \(\psi\) |
| 都在死区内 | 冻 | 冻 |

转向不得重置位置原点。前进不得重置朝向原点。

### 3.3 训练里不用 Kalman

把左右轮和 yaw 融合成 pose，在估计器里消矛盾，概念上对，但不能放进 PPO：

- 训练优化的是观测里的伺服。滤波器每步改写误差，目标带滞后，策略会学“估计器替我圆场”。
- 仿真接触经常不满足无滑移，过程/观测噪声会变成另一套超参；reset 后的滤波暂态会污染前期奖励。
- 若训练要故意拉开位置或朝向误差，滤波器会当场收成自洽 pose，拉开等于没做。

融合只属于部署时的状态估计。训练保证目标定义自洽：两个量，注入一次只动一个原点。

推理可以 Kalman，也可以仍用本节的代数分解。估计的是当前 \((s,\psi)\)，hold 仍相对冻结的 \((s_0,\psi_0)\)。滤波器不改原点。倒地、站起时把轮观测噪声加大，航向更信 IMU。

## 4. 训练

### 4.1 观测

保留现网 26 维槽位，改语义：

- 朝向槽：\(\Delta\psi\)
- 两个轮槽：都填 \(\Delta s\)。看均值是位置，看左右差是 0，不会为拧回旧相位去转。

不要填 \(\theta_i-\theta_{i0}\)。必须重训。

### 4.2 奖励

- 位置：\(f(\lvert\Delta s\rvert)\)，仅前进指令在死区内激活。
- 朝向：\(f(\lvert\Delta\psi\rvert)\)，仅偏航指令在死区内激活。
- 大误差仍可用线性代价，作用在 \(\Delta s\)、\(\Delta\psi\) 上，不要按左右轮分别罚。
- 左右腿差是腿的问题，可单独罚，与里程计无关。

### 4.3 注入

> 注:本节机制曾以 `hold_recovery` 落地,后被证明是补丁(双锚点语义本身已治好原病)
> 且训练退化,已整体移除——见 `docs/hold_recovery_training.md`(消亡史)。
> 本节保留作为历史设计记录,当前代码无注入/锁定/随机初始化通路。

进入停车的上升沿，以概率只做一件事：

1. 只偏位置：\(s_0 \leftarrow s - U(-E_s,E_s)\)，\(\psi_0\) 不动  
2. 只偏朝向：\(\psi_0 \leftarrow \psi - U(-E_\psi,E_\psi)\)，\(s_0\) 不动  

注入后强制一段时间零前进、零偏航，让两路伺服有时间收。随机初始姿态仍然有用：站起后 \(s,\psi\) 相对 reset 原点会偏，这就是要练的大误差。开局零指令、推迟第一个非零命令，覆盖“站起 + 冻原点”。

## 5. 推理

与训练同一对误差、同一套刷新规则。

- 当前 pose：默认代数分解；打滑、接触差时再上 Kalman，输出仍是 \((s,\psi)\)。
- 出训练分布时：只把送进网络的 \(\Delta s\)、\(\Delta\psi\) 夹到训练带内，**原点不动**。收回到带内后，观测与真误差重新一致。界面上仍显示相对 \((s_0,\psi_0)\) 的真误差。
- 旧策略不能直接吃新观测。兼容层（把 \(\Delta s,\Delta\psi\) 拆回左右相位填旧槽）不是本方案。

1. 环境内部改为 \(s,\psi\) 与 \(s_0,\psi_0\)，刷新按第 3.2 节。
2. 观测轮槽改为 \(\Delta s\)；奖励改为位置项 + 朝向项。
3. ~~注入只偏 \(s_0\) 或只偏 \(\psi_0\);注入后锁零指令一段时间;训练 reset 可用随机姿态并推迟首个命令~~(已随 hold_recovery 移除,见消亡史)。
4. 推理：出分布只 clip \(\Delta s,\Delta\psi\)，原点不动。
5. 单测：前进不刷 \(\psi_0\)；转向不刷 \(s_0\)；共模轮转只增 \(\Delta s\)；IMU 航向变化只增 \(\Delta\psi\)；~~一次注入只有一路大误差~~(已随移除删除)。
6. 新训后再复现“随机站起 → 蹲稳 → 伸直”：\(\Delta s\)、\(\Delta\psi\) 应下降，而不是停在很大的相位误差上。
7. Kalman 仅推理、可选；默认代数分解。滤波参数不进 PPO。
