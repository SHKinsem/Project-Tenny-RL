# 物理初始化对齐后的±1与±2 N·m对照

2026-11-16。**两组确定性0步物理行为已对齐；本轮±2没有一致改善原地平衡。** 累计合格时间的三个配对差为+.163333/-.186667/-1.073333秒，仅1/3增加，配对中位差-.186667秒。两组全部六个训练seed的主要累计合格时间都低于共同BC初始化3.970秒。

## 对齐与冻结条件

两组策略都在共同Fs2≈17.743N请求坐标中输出。±1执行容量仍为Fs1≈8.8715N及motor±1N·m；±2为Fs2及motor±2。相同动作不会因组别被乘不同尺度，而是先形成相同物理请求，再按各自容量裁剪。轮仍±.0295N·m。

两组共同使用冻结BC均值锚点：`mu = atanh(r*tanh(mu_BC)) + (mu_train-mu_BC)`，`r=.5*(1-2^-20)`。初始mutable参数是原BC，差项为0；训练后差项可使用完整请求范围，不是永久减半输出。原可训练参数数量、Gaussian std参数、critic、固定normalizer与wheel head均保留；冻结锚点不进入optimizer参数树。此共同head改变了相对旧实验的参数化，因此**两组都重新训练，旧±1结果没有复用**。

原奖励/权重不变，不加姿态或真实位移项；能耗、动作变化、前拍扭矩观测的物理归一化固定[1,1,.0295,.0295]。训练回合30秒/外层3000步，策略100Hz、物理400Hz，原零命令/无观测噪声推力域随机化、512环境/batch512、unroll16、1 minibatch/1 update、lr3e-5、entropy.001、reward_scaling.1、gamma.9862327044933592、lambda.9025均固定。每组3seed，每次2,097,152步，共12,582,912步，优化器均重建。

初始化实际核验：

- 五初态下两组observation/action/qpos/qvel/ctrl/reward逐点差全0，终止原因/时刻相同。首回合时长[6.20,5.82,5.64,5.66,9.03]秒，主要累计合格时间均3.970秒。不存在上轮±2初始化.62秒失败的问题。
- 同状态同key42的1000个样本，logits、采样动作与pre-cap物理腿力请求差全0。**这是随机请求对齐，不能解释成所有随机实际输出也相同**；探针中右腿5.4%的请求超低组Fs1容量，之后的实际裁剪差异就是实验处理。
- JAX与原生策略动作最大差8.34e-7；改变mutable腿均值后可达.9879动作，导出差2.38e-7。较大请求探针在两组输出约.885/1.682N·m，确认额外能力没有被补偿头消掉。
- 数值余量r使相对旧BC的归一化物理力参考误差约1.07e-6；“误差0”指两新组之间，不指旧BC所有轨迹逐点不变。两组主要0步指标与旧BC相同。

## 统一结果

两组0步参考与六个最终策略，各五个同样实际初态，共40条最长30秒首回合。每seed先平均标称/±.01rad三个主要初态，再汇总三个seed；预留±.02rad单列。固定初态不是额外独立训练重复。

## 容量是否实际用到

±2最终策略的末物理子步命令峰值最大1.303686N·m，确有使用原1N·m之外的范围。标称seed1左/右峰值1.0643/1.0032，seed2为1.0429/1.3037N·m。

所有±2最终策略的合格区间里，没有采样到>1N·m命令；高容量组部分合格区间的请求超过旧Fs1包络，按case/单腿最高约4.27%。因此不能将“合格时未出现>1Nm采样”扩大为“没使用额外腿力包络”。这些幅值来自100Hz末子步ctrl、由单位gain/gear理想motor力律推得，不是全400Hz峰值采集或硬件实测。

40条首回合总25,627控制步/102,508物理子步，原生post-guard raw扭矩裁剪聚合均0。force容量裁剪与motor硬裁剪不同：低组可在|action|>.5时触及Fs1容量，仍不一定达到1N·m。`actuator-usage.json`分别记录请求超Fs1/本组容量、命令>1、合格区间占用和原生raw裁剪；非零raw聚合不是裁剪时间比例。

## 验证与归因边界

- 实际两组包装链均为BraxAutoResetWrapper→EpisodeWrapper(3000)→VmapWrapper→AlignedLimitEnv；真实编译的腿ctrl/force范围分别±1/±2，reward/观测分母保持原值。
- 六次训练的完整初始化digest均`a983df4f3e27d12b10e022303e1c7fad0c6c6f97de13d5adde0257321096d393`，固定normalizer漂移0、actor有更新，六checkpoint各25参数叶有限、重载精确。用正确新head和冻结anchor重新导出与完整descriptor完全一致，anchor未变化。
- **裸checkpoint三元组不能单独恢复完整新策略**，需同时保留冻结BC anchor及新head；完整descriptor已含anchor。不能用旧24维/4动作模型加载路径仅凭维度猜兼容。
- 40条短/长评价共同前缀逐点一致。独立从原轨迹重算累计/最长/存活、主/预留均值与所有配对字段误差0；独立比较两份0步物理与奖励也全0。
- 原16保护文件、4旧checkpoint树、32冻结运行时文件、13份复制资产及基础源/资产指纹不变。基础指纹`4ca2bc7387038679a16eaedde390b4f4db7b6e678007d83fba268ccc9137960a`，新实验指纹`c94269afa42c490c2151d4b3894f2b8a8f7b336f5e3606be065bf39c251a6675`。
- 独立审阅确认：采样与PPO loss使用同一替换后的网络；head只重参数化Gaussian均值，原raw_action/log_prob机制成立，不需额外head Jacobian。容量clip在环境中，冻结anchor为closure常量不参与优化，normalizer统计固定是必要条件。
- 本轮比较有效范围是共同新head下的两种执行容量；与历史旧head实验的差异不能全部归因于上限。3配对seed、固定初态和本预算不证明显著性、收敛、其他初始化/预算或实机能力；不能把未见一致收益说成±2永远无用。
