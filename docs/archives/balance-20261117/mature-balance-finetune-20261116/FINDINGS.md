# 成熟模型的真实位置微调：结果与退化原因

2026-11-16。**找回成熟模型后，可以保住平衡并学到更小的位置偏置；从头把学习率降十倍，本预算内反而更差。训练中出现过约2毫米的较好策略，继续更新又退化。旧轮角目标与真实位置目标的排序冲突也有直接分项证据。**

## 起点已纠正

用户指出比较前已经有能平衡但漂移的成熟模型。这一纠正成立：按原动作语义筛查25个同源码指纹历史checkpoint，10个在标称/±.01rad三个初态均撑满30秒。按三个筛查工况最大真实位移最小选择旧run `20261115T081557.290279Z_bd32fd40` 的 `000002801664`；checkpoint SHA为`b177fb73cd6566e96fcaefcb5c8ecd2324de53f8318fa82cf74684476803aa5d`。选择后再验证预留±.02rad，共五初态均完整120秒。原模型启动后的位置偏置约1.5～2厘米，之后没有持续走远。

此前六次对齐容量短训都从BC初始化开始，不能替代这个成熟模型；BC的未训练critic等诊断也不能外推到成熟模型。对应审计另见`../training-regression-audit-20261116/FINDINGS.md`。

## 本轮条件与最终对照

用户选择加入真实XY奖励。两组均从同一个成熟normalizer/actor/critic完整恢复，保留原动作头与±1N·m/Fs1及轮扭矩映射，不使用aligned锚点补偿、不重新BC。两组共享新增项`10*expm1(-(||XY-XY_reset||/.05)^2)`；原奖励、观测和权重保持。真实原点在reset固定。

两组只改变固定学习率：3e-5与3e-6，各3个配对seed，每次2,097,152步，总12,582,912步。外层30秒、100Hz策略/400Hz物理，512env/batch512、unroll16、1 minibatch/1 update、原gamma/lambda/entropy等固定。旧force PPO包装器会强制3e-5，本轮独立入口直接调用同一Brax训练器，实际日志分别记录2.999999924e-5与3.000000106e-6，未启用动态调节；其余固定标准化/factory/wrapper/完整restore与真实部署源逐项对照。

每262144步保存独立策略descriptor、五初态30秒回放及奖励/物理指标，共9个阶段；最终六模型与不更新参考在同样五初态统一评价120秒。**35/35首回合均time_limit，没有提前终止；5厘米联合合格时间均119秒，已封顶，不能据此区分谁更稳。**

三个seed的120秒末段配对差（低减高）为+9.270/+10.884/+12.597mm，中位+10.884mm，3/3低学习率更差。两组各自中位数之差+10.221mm不是配对差的中位数。预留工况参考17.399mm、高组中位13.497mm、低组23.725mm，配对中位差+10.884mm，同方向。

高学习率三个seed末段偏置均低于未更新参考，但启动最大位移和速度RMS变大：前120秒最大位移的seed中位为31.563mm，参考19.469mm。因此不能称全面改善。低学习率在部分启动指标较小，也不能说所有维度都更差。以上仅为当前共同真实位置目标、固定预算的学习率比较，不证明低学习率在更长预算或分开调actor/critic时永远无用。

## 曲线中保留下来的较好策略

从48个非0步的保存阶段中，事后按三个主初态30秒真实XY RMS最小选择：`high_lr-seed-1`，第1,048,576步。未用预留两个初态排名，也没有新增训练。这是探索性挑选，不能当作第四个训练seed或三seed一致结果。

该策略再做五初态120秒回放，全部撑满：主要初态末10秒平均位移**2.161mm**、120秒RMS2.949mm；预留初态分别为**3.181mm**、3.740mm。独立复算误差4.34e-19，descriptor身份一致。标称末段1.902mm；启动仍有25.273mm峰值，120秒航向变化约8.22°，不能称所有自由度完全静止。已实际查看[120秒物理曲线](selected-stage/comparison.png)。

同seed继续到最终2,097,152步后，主要初态120秒末段位移回到13.704mm；因此“更新会把已经更好的位置保持推偏”有直接保存策略和长回放证据。

**恢复边界：** 中间策略descriptor（本机原始资料，未入此归档）保存了完整确定性actor/normalizer推理，可回放；没有这个中间时刻的完整critic/std参数及优化器历史，不能当作完整PPO续训checkpoint。六个最终目录保有完整normalizer/actor/critic参数，续训优化器仍重新建立。没有拼接最终critic冒充中间checkpoint。

1. **目标排序不等同于原地保持。** 9.615mm策略虽然离起点更远，总目标回报仍比2.115mm策略高15473.524。其旧轮角保持项多14139.980、航向项多2161.228，超过真实位置项改善934.223。只是加一个真实位置项，没有消除旧轮角目标主导奖励排名的可能。这是明确的奖励排序证据，不是已证明某一项单独造成所有梯度问题。
2. **后续更新也会退化。** 从1048576到最终，位移和合成回报同时变差，不能全部解释成策略成功优化了错误奖励；它没有在固定确定性评价中提高合成回报。稀疏loss/KL不足以唯一定位哪次梯度或critic估计出了问题。
3. **学习率过大不是本轮已成立的唯一解释。** 从头降十倍的组，三seed都没有得到更小偏置。当前是actor/critic共用的学习率；未试后期衰减、分开学习率或最优策略保护，不能将这些方案声称为已验证修复。

因此后续合理方向是保留较好策略并按真实物理指标选模型、处理旧轮角代理与真实位置的竞争，再单独验证后期学习率调整。当前不自动改奖励权重、追加训练或替换生产模型。
