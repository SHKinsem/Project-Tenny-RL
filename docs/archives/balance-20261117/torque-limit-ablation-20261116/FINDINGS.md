# 原奖励下腿力矩±1与±2 N·m配对对照

2026-11-16。**本轮扩大到±2N·m并同步将腿力范围翻倍，没有改善原地平衡。三个正式seed的累计合格时间均0，主要初态约0.63秒触发俯仰终止。** 同一BC参数经过扩大后的动作映射，0步闭环表现已经从约5.89秒终止前时长变为约0.62秒；本轮短训没有恢复该起始表现。

本轮检验的是“扩大执行/F动作范围、沿用同一完整BC参数继续训练”这套方案。没有测试物理输出等价的初始化，不能据此认定更大力矩能力本身无价值、±1已足够，或其他初始化/预算也会失败。

## 冻结条件

| 项目 | ±1基线 | ±2实验 |
| --- | --- | --- |
| 两腿实际motor ctrl/force范围 | ±1N·m | ±2N·m |
| 两轮限制 | ±.0295N·m | 相同 |
| F标定公式 | .9×limit/Jmax | 相同公式 |
| 左/右虚拟腿力尺度 | 8.871533 / 8.871519N | 17.743066 / 17.743038N |
| 奖励、前拍扭矩观测及变化率归一化 | [1,1,.0295,.0295] | 保持基线尺度 |
| 训练回合 | 30秒，外层3000步 | 相同 |
| 策略/物理频率 | 100/400Hz | 相同 |
| 初始化/预算 | 同一完整BC、固定normalizer，3seed，各2,097,152步 | 相同，从BC重新开始 |
| 运行来源 | 复用最近30秒组三seed | 本轮新训练三seed |

原奖励不增加姿态或真实位移项，不改变任何权重；固定扭矩归一化避免同一物理扭矩在±2下被少罚。几何/Jmax/保护边界、零命令、无噪声/推力/域随机化、512环境/batch512、unroll16、1 minibatch/1 update、lr3e-5、entropy.001、reward_scaling.1、gamma.9862327044933592、lambda.9025均一致。优化器均重建，smoke权重不进入正式训练。

## 结果

统一五个固定物理初态，首回合最长30秒；每训练seed先平均标称与±.01rad三个主要初态，再对三个seed显示中位数[min,max]。预留±.02rad单列。累计合格时间从第1秒后开始计，要求俯仰误差≤10°、真实机身XY位移≤5cm、平面速度≤.1m/s同时满足，按真实区间两端均合格求和，最长连续段另计。

| 条件 | 累计合格秒 | 最长连续合格秒 | 环境终止前秒 |
| --- | --- | --- | --- |
| ±1的0步BC | 3.970 | 3.903 | 5.887 |
| ±2的0步BC | 0.000 | 0.000 | .623 |
| ±1训练后，复用 | 3.203 [2.877,3.270] | 3.133 [2.857,3.190] | 7.230 [6.057,8.280] |
| ±2训练后 | 0.000 [0,0] | 0.000 [0,0] | .630 [.627,.637] |

| seed | ±1累计合格 | ±2累计合格 | 配对累计差 | ±2主要初态终止前时长 |
| --- | --- | --- | --- | --- |
| 0 | 3.270 | 0.000 | -3.270 | .636667 |
| 1 | 3.203333 | 0.000 | -3.203333 | .626667 |
| 2 | 2.876667 | 0.000 | -2.876667 | .630000 |

累计合格配对中位差-3.203333秒，最长连续段差中位-3.133333秒。±2三个seed的预留初态累计合格也均为0。40条统一评价均提前终止，其中±2的两类0步/最终策略共20条均为pitch终止。环境终止条件不是独立的首次触地检测，不把终止前时长直接称作一直直立。

**各自0步增量的“正差”是地板效应，不能称为学得更好。** ±1累计由3.970降到训练后中位3.203，±2是0→0，所以两组增量之差为+.767秒。这来自±1的下降和±2已在0下限，没有显示±2学出了合格原地平衡。HTML紧邻该数字与paired-summary.result_reading_notes已明确提示。

±2标称回放腿命令峰值约1.77N·m，确实使用了原1N·m以外的范围。三个最终seed的标称末子步样本中，左腿>1N·m占54.8～58.1%，右腿79.4～82.3%；这些是100Hz末物理子步命令样本占比。不能把它们当作全400Hz幅值占空比或实机测量。40case首回合共16,015控制步/64,060物理子步，原生raw硬裁剪聚合均0；非零时该聚合本身不等于裁剪时长比例。

同一BC网络输出乘上更大的F尺度，最初施力已经变化；0步参考准确捕捉了这件事。当前证据支持“直接扩展动作范围并沿用现有初始化的方案，在本轮预算内失败”，不足以单独判断最佳电机上限。后续若继续研究能力范围，应先处理扩大动作映射后的初始化匹配，再预先冻结新的公平对照；本轮没有追加调参或新的实验。

## 等价与完整性验证

- 独立native副本只增加可选torque_normalization_scales，缺省沿用旧尺度，未替换生产评估器。±1的BC与三个最终策略共20条旧回放，observation/action/qpos/qvel/ctrl/reward逐点误差0。
- 以两组动作幅度相应匹配同一物理扭矩，3初态×128步的观测、状态、命令和奖励误差均0，验证原奖励/观测单位没有随2N·m被放松。两个XML实际编译的腿ctrl/force限制分别为±1/±2。
- 冻结训练环境的_step_control与原版AST只差裁剪诊断使用执行上限；所有reward/current/history物理单位保留原尺度。末次实际构造的包装链为BraxAutoResetWrapper→EpisodeWrapper(3000)→VmapWrapper→TorqueLimitEnv；不是仅引用上轮包装链。
- 每次正式训练精确2,097,152步，新增共6,291,456步；矩阵墙钟420.536秒（7.01分钟，含进程准备/JIT/训练/过程评价/保存，不含前置验证与报告整理）。新路径独立8192步smoke47.060秒，不计入正式预算，参数不被复用。
- 六组完整BC初始化数组digest一致为`a983df4f3e27d12b10e022303e1c7fad0c6c6f97de13d5adde0257321096d393`；normalizer漂移0，actor均更新。三个新checkpoint各25个参数叶有限，重载精确，重新从已存actor导出与descriptor完全一致。
- 40条短/长共同前缀逐点一致；独立从原始轨迹重算累计/最长/存活、主要初态均值与所有配对字段误差0。固定初态不是额外独立训练重复，不宣称显著性、收敛或实机鲁棒性。
- 16保护文件、4旧checkpoint树、3复用模型、17个冻结运行时文件、13份复制资产及原模型源码/资产指纹保持。基础指纹`4ca2bc7387038679a16eaedde390b4f4db7b6e678007d83fba268ccc9137960a`，独立实验身份`4271ee39e8767bebb9c4ec42413958cc20622393ea382fcf976fdcbb49ada9b0`。
