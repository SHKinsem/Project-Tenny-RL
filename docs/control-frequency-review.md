# 腿力控制与位置伺服的反馈层级

2026-11-16只读核对。本文说明当前仿真与控制结构，不代表已验证的频率瓶颈或实机闭环频率；本轮6/30秒训练回合实验没有改变控制频率。

## 当前项目事实

| 层级 | 原作者腿位置控制 | 当前腿力＋轮扭矩 |
| --- | --- | --- |
| 策略更新 | 100Hz | 100Hz |
| 物理积分 | 实际400Hz | 实际400Hz |
| 腿执行 | 位置目标由PD伺服跟踪，物理子步根据当前位置/速度重算力矩 | 每10ms给虚拟腿力，每2.5ms依据构型更新力到扭矩映射 |
| 腿位置/速度误差反馈 | 位置伺服包含 | 没有同一个位置伺服；状态纠偏主要由策略负责 |
| 原生扭矩执行器 | 轮使用无激活动态的直接力矩电机 | 四路均为单位增益、无bias/激活动态的直接力矩电机 |

实际source入口是`experiments/torque200/wheel_teacher/teacher.py`的`AuthorTeacher.step`、`hybrid/env.py`的`_step_control`和`force_teacher/env.py`。原作者老师还在四个物理子步内更新轮速反馈；腿位置＋直接轮扭矩学生关闭这段轮速反馈，但保留腿位置伺服，不能把三种模式混成同一种控制链。

源XML默认`timestep=0.004`不能用来推断运行频率：训练`LegWheelRobot`初始化明确将模型步长覆盖为`config.sim_dt=0.0025`，老师也明确覆盖；实际原生Evaluator报告0.0025。程序运行值才是本轮400Hz的依据。

## 力矩权限也是差异

实际编译的参考位置执行器为`kp=120`、`kv=80`，单位gear，输出限幅±24N·m；当前力模式腿电机输出/命令限幅±1N·m。两者都没有额外joint actuator-force限幅。这里是仿真关节输出配置，不是已确认的实机能力，也不说明策略实际用到了24N·m或1N·m已不够。当前轮命令仍由控制层限在±0.0295N·m，不能仅看XML的±0.04N·m范围。

因此，跨位置/力模式的表现差异同时包含内层反馈结构和力矩上限等变化。没有实测力矩占用和匹配条件对照前，不能把差异单独归因于策略频率。6秒/30秒训练对照的两组都保持同一±1N·m腿限幅，不受这个跨模式差异混淆。

后续已只读追溯该暂定尺度并检查35条保存策略回放：全物理子步无硬裁剪，腿力动作近满幅主要出现在持续离带后，右腿启动阶段也明显出现。来源、统计口径和限制见[限幅专项核对](torque-limit-review.md)，不把无硬裁剪解释成能力已经验证足够。

## 电流环与策略频率

MuJoCo `motor`在此处为`dyntype=none`、固定gain=1、bias=0、gear=1，限幅内直接得到命令力矩；未显式模拟PWM、电流采样、电流建立或电流控制器带宽。真实硬件的电流环用于实现请求的扭矩，位置/速度环则使用机械状态误差生成扭矩目标。仿真中的理想力矩跟随不能检验真实电流环是否足够快。[MuJoCo motor定义](https://mujoco.readthedocs.io/en/stable/XMLreference.html#actuator-motor)、[ODrive控制结构示例](https://docs.odriverobotics.com/v/latest/control-input-modes.html#structure)

位置伺服的力律包含`kp*(target-position)-kv*velocity`，目标不变时仍会依据新状态重算输出。`J(q)^T*F_hold`更新的是构型到扭矩的映射，本身没有补回相同的位置目标/速度误差控制器。这里的“400Hz更新映射”不能直接当作“400Hz腿位置稳定环”。[MuJoCo执行器力生成](https://mujoco.readthedocs.io/en/stable/computation/index.html#actuation-model)

本轮没有读取实机电机/驱动器内环配置或测得闭环带宽，因此不指定实机内环Hz数，也不声称必须1kHz。

## 后续独立验证

若测100/200Hz策略更新，物理先固定400Hz，分别每4/2个物理子步刷新策略；实际更新必须使用新状态，重复旧扭矩不是更高频反馈。

按物理时间匹配unroll（当前100Hz×16步=.16秒，200Hz对应32步）、reward积分与动作变化率定义、gamma/GAE衰减时长、延迟/滤波/历史窗口以及仿真时间与优化预算。当前gamma100=0.9862327044933592、lambda100=.9025；按相同指数时间尺度，200Hz的gamma为平方根、lambda=.95。模型和策略接口另行验证，不能简单改Hz后沿用所有步数。

这可以检查较快策略是否有收益，但不能直接归因于实机电流环，也不能从100/200Hz外推到1kHz。若比较原位置模式，还须明确匹配力矩权限及内层反馈结构。本轮仅记录此方向，没有执行新的频率训练。
